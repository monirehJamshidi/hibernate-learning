# Hibernate Learning Project

A hands-on Java project for learning Hibernate and JPA
with Oracle Database.

## Topics Covered

- JPA and Hibernate
- Entity Lifecycle
- Persistence Context
- Dirty Checking
- persist() and merge()
- flush() and commit()
- Optimistic Locking with @Version
- One-to-Many / Many-to-One
- mappedBy and JoinColumn
- Lazy and Eager Loading
- LazyInitializationException
- N+1 Query Problem
- JOIN FETCH
- Cascade
- orphanRemoval
- JPQL
- Native Queries
